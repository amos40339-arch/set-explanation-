Two rules of every set

No repeats. No order. {1, 1, 2} = {2, 1}

The tricky ones (think "bag")

QuestionAnswerWhy
∅ ⊆ {1,2,3}Yes∅ is a subset of every set
∅ ∈ {1,2,3}NoThe items are only 1, 2, 3
∅ ∈ {∅,1,2,3}Yes∅ is listed as an item
{x} ∈ {x,{x}}Yes{x} is the second item

The laws

LawSymbolsPlain meaning
IdentityA ∪ ∅ = A, A ∩ U = AAdding nobody changes nothing
DominationA ∪ U = U, A ∩ ∅ = ∅Join everybody, get everybody
IdempotentA ∪ A = A, A ∩ A = AA with itself is itself
ComplementA ∪ A′ = U, A ∩ A′ = ∅In A or not covers all; nobody is both
Double complement(A′)′ = ANot-not in A = in A
CommutativeA ∪ B = B ∪ AOrder doesn't matter
Associative(A ∪ B) ∪ C = A ∪ (B ∪ C)Brackets don't matter (same sign)
DistributiveA ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)Like a(b + c) = ab + ac
De Morgan(A ∪ B)′ = A′ ∩ B′, (A ∩ B)′ = A′ ∪ B′Break the bar, flip the sign

Formulas for word problems

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A∩B) − n(A∩C) − n(B∩C) + n(A∩B∩C)
3 circles: start from the middle, subtract your way out.
